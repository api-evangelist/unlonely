# Unlonely

> Unlonely was a crypto/web3 livestreaming platform — livestreams on Base with token-gated chat, creator tokens, on-chain viewer interactions, and stream clips minted as "NFCs" (non-fungible clips) to Zora. Founded by Grace and Brian Guan and backed by Multicoin Capital. The product is defunct: the unlonely.app domain registration has expired (Namecheap parking page as of 2026-07) and the hosted GraphQL API is no longer live. The open-source monorepo remains public and this profile preserves its API surface.

Generated by API Evangelist from apis.yml and repo artifacts on 2026-07-21 (method: generated — the provider never published an llms.txt).
